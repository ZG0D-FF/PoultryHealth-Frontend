01 / Executive Brief

60-Second Summary & Rapid-Recall Numbers.

Examiners judge confidence by how cleanly you recall core metrics and state limitations upfront. Always report both the random split (90.8%) and session-isolated accuracy (65.4%) together.

60-Second Viva Pitch · Verbatim

“Respiratory diseases spread fast in poultry sheds and are usually noticed only when birds look sick. We built a low-cost, offline system that listens to the flock. Audio is band-pass filtered to 300–4000 Hz, a pretrained YAMNet network discards non-bird sounds, and 80 acoustic features are classified by five classical models combined by an MLP meta-learner. MFCC extraction runs on an ESP32-S3, a 6.3 KB neural network on a second ESP32, and the full ensemble on a Raspberry Pi. We reach 90.8% on a random split, but 65.4% on recording sessions never seen in training, and we explain exactly why that gap exists and how to close it.”

Scope: Classifies Healthy / Sick / Noise vocalisations — never named pathogens. Field Basis: Haringhata Meat (WBLDC)

Root-Cause DiagnosisSection D6

Four Causes of the 90.8% → 65.4% Gap

01

Session Leakage in Random Split

Clips from the same shed/mic appear in both train and test, allowing the model to recognise room acoustics rather than pathology.

02

HDBSCAN Pseudo-Label Noise (1,828 clips)

Masked autoencoder (MSE 0.0072 → 0.0028) + heuristic clustering (largest cluster = Healthy) introduces unverified label noise.

03

Sparse 3rd Class (Noise F1 = 0.01)

Classifier had too few Noise examples; mitigated in deployment by upstream Silence + YAMNet bird gates.

04

Cross-Site Microphone & Fan Shift

Real acoustic shift across recording rooms — solved next via short per-shed normal-condition calibration.

Unit EconomicsSection E1–E2

Rs 1,000–1,350 / Acoustic Node

Cost and accuracy are decoupled: MFCCs run at ≈2.6 MFLOP/s (≈1% of one ESP32-S3 core) with zero cloud GPU or subscription fees. Accuracy is bounded by vet-confirmed data, not compute.

Portability ThresholdSection E3

78 KB RAM · Plain C++ Firmware

Runs MFCC + TinyML together on ESP32, ESP32-S3, STM32F4/H7, or nRF5340 (requires I²S, FPU, ≥78 KB RAM). Cortex-M0 (32 KB, no FPU) excluded. Pi stack runs on any Linux board / Android Termux.

6-Month RoadmapSection F10

From Prototype to Field-Ready

(1) Collect vet-confirmed Haringhata labels; (2) Retrain purely on session-isolated splits with per-shed calibration; (3) Measure hardware power & latency; (4) Run a 2-week logged field pilot.
